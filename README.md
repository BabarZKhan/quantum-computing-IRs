# quantum-computing-IRs

A curated catalog of intermediate representations (IRs) for quantum computing:

Language extensions:
- [QIR](https://github.com/qir-alliance/qir-spec)
- [Q-MLIR](https://github.com/ORNL-QCI/qcor)
- [QSSA](https://github.com/opencompl/QMLIR)
- [QIRO](https://github.com/dime10/QIRO)

Standalone:
- [SQIR](https://github.com/inQWIRE/SQIR)

IR frameworks:
- [XACC IR](https://github.com/eclipse-xacc/xacc)
- [QBIR (Yao.jl)](https://github.com/QuantumBFS/Yao.jl)
- [t|ket⟩ IR](https://github.com/Quantinuum/tket)

Distributed (DQC):
- [InQuIR](https://github.com/team-InQuIR/InQuIR)
- [NetQIR](https://github.com/NetQIR/netqir-spec)

Misc:
- [SIQPII](https://yawlang.dev/SIQPII/preview.html)
